# Muhammad Basit

I work on handheld Linux, Android apps and native Mac tools. Most of it started with something I wanted to use myself.

## Projects

- **[SteamOS on ARM handhelds](https://github.com/hashtagbasit/SteamOS-ARM-Handhelds)** — Valve's SteamOS Frame build on the KONKR Pocket FIT. Pocket S2 support is still experimental and needs testing on a device.
- **[LSFG-VK for ARM64](https://github.com/hashtagbasit/lsfg-vk-arm64)** — frame generation work for ARM Linux handhelds.
- **[Valkyrie](https://github.com/hashtagbasit/valkyrie)** — a native Mac app for downloading and flashing Samsung firmware.
- **[aimal-patches](https://github.com/hashtagbasit/aimal-patches)** — practical fixes for Crunchyroll, HBO Max, Disney+ and Viki.

I care about the less visible parts too: installs, updates, controls, thermals and the bugs you only find on real hardware.
